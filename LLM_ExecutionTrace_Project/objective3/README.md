# Objective 3 — Causal Diagnosis Model for Self-Correction

This is the implementation of **Objective 3**: the integrated closed-loop self-correction architecture.

## Overview

The system takes failing code generated by LLMs, uses Objective 1 for error classification, and Objective 2 for causal root-cause diagnosis. It then implements a feedback-controlled repair cycle up to 5 iterations.

The system uses a 4-component repair prompt methodologically specified as:
1. Specification
2. Fault Localization
3. Error Classification
4. Repair Strategy

Code is merged using an AST-based merger that respects boundaries and preserves function signatures.

## Architecture Highlights
- **AST Merger (`ast_merge/`)**: Code replacement at the AST level avoiding naive regex replacements.
- **Controller (`controller/`)**: Explicit finite-state machine (FSM) detecting SAME_ERROR stalls, NEW_ERROR transitions, and OSCILLATION loops.
- **Executor (`execution/`)**: Isolated subprocess sandbox.
- **Exporters (`exporter/`)**: JSON/CSV/Excel exporters capturing rich data required for Objective 4 analysis.
- **Ollama Client (`ollama/`)**: Robust LLM access with exponential backoff.

## Execution

Ensure Ollama is running on localhost (or configure base_url), then run:

```bash
python objective3/main.py
```

Options:
- `--limit N`: Limit to N tasks for testing.
- `--verbose`: Enable debug logging.
- `--model NAME`: Override the Ollama model.

## Tests

Run the test suite:

```bash
python -m unittest discover -s objective3/tests -p "test_*.py" -v
```
